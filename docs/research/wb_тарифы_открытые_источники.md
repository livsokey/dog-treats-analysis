## 3. Логистика, хранение, приёмка (официальные цифры WB на 01.11.2026)

Ключевое: с 15.08.2026 для всех складов РФ единый коэффициент доставки и хранения 170% (малогабарит), 100% для сверхгабарита. Индекс локализации равен 1,00 для всех, ИРП отменён с 13.07. Поэтому таблицы «Коледино против Электростали» с разными коэффициентами больше не отражают тарифы. Склады СНГ считаются отдельно (в кабинете).

## 4. Эквайринг (приём платежей)

Официальная формулировка (оферта, п. 12.10): издержки WB на комиссии банков и платёжных систем «не включаются в сумму издержек, вычитаемую из суммы вознаграждения» и «возмещаются сверх такого вознаграждения»; размер еженедельного удержания определяется по тарифам банков и платёжных систем и сумме принятых платежей; итог подтверждается отчётом об издержках на приём платежей (https://seller.wildberries.ru/instructions/ru/ru/material/calculating-remuneration-rules-and-fbs-acceptance-procedure). То есть эквайринг идёт сверх КВВ. Процент в открытых официальных источниках не опубликован. Из вторичных: SelSup пишет об эффективной ставке 2,74% за май (статья обновлена 15.09.2026, база расчёта — цена до СПП); это не официальная цифра.

## 6. Правила WB для кормов и лакомств

- Разрешительные документы: с 01.10.2026 реквизиты сертификата/декларации/СГР обязательны в карточке; ТН ВЭД и ОКПД2 в карточке должны совпадать с документом, иначе карточка блокируется. Если документы не нужны, ставится галочка «Документы, подтверждающие безопасность, не требуются»; отказные письма загружать нельзя (справка WB 08.10.2026).
- Ветеринарные: «Корма для животных, лакомства... для неё нужны эВСД» через «Меркурий»; для FBW нужно связать площадку «Цербер» со складом WB, сам WB указал список СЦ, подведомственных «Меркурию» (Казань: Столбище, Чехов, Владивосток, Воронеж, Омск, Белые столбы, Чертаново, Истра, Домодедово-2, Подольск, Краснодар: Тахтамукай-2, Казань, Коледино). Для FBS связь с WB не нужна. Товар с эВСД недоступен покупателям из других стран ЕАЭС (справка WB 11.09.2026).
- Честный знак: WB требует КИЗ на каждую единицу для маркируемых групп, GTIN 14 цифр, галочка «Нужна маркировка КИЗ» ставится автоматически или вручную; GTIN проверяется через ГИС МТ с 01.10.2026; вывод из оборота продавец делает сам, возврат в оборот в течение 3 дней при отказе (пост WB 06.10). В самой справке WB корма как группа не названы, но по ПП РФ № 674 (markirovka.ru): сухие корма и лакомства (ТН ВЭД 2309, ОКПД2 10.92.10.100–199) с 01.10.2024, влажные (10.92.10.200–299) с 01.03.2025; ОСУ с 01.09.2025 до 30.11.2026; поэкземплярный учёт с 01.12.2026. Значит, в ноябре 2026 КИЗ на каждую единицу нужен.
- ПФЦ пока не принимают товары с КИЗ (пост WB 09.10, «функционал в разработке»); пищевая продукция недоступна для FBW через ПВЗ.
- Витамины и добавки для животных: по обзору uniseller.io нужно СГР (вторичный источник, не WB).
